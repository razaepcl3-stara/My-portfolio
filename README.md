# Ammar Abbas — Portfolio Website

A responsive one-page creative portfolio built with plain HTML, CSS and JavaScript, ready for GitHub Pages.

## Files
- `index.html` — website structure/content
- `styles.css` — responsive styling and animations
- `script.js` — portfolio filters, Google Drive previews, mobile navigation and reveal effects
- `Ammar-Abbas-Resume-2026.pdf` — downloadable resume
- `assets/logos/` — company logos used in the experience section

## Publish on GitHub Pages
1. Create a new public GitHub repository, for example `ammar-portfolio`.
2. Upload all files and folders from this package to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. GitHub will provide a public URL such as `https://YOUR-USERNAME.github.io/ammar-portfolio/`.

## Customize
Portfolio items are defined in `script.js` inside the `projects` array. Edit titles, Google Drive links or categories there.

For video previews to work, each Google Drive file must have sharing enabled so visitors can view it.
